# Mint Android Automation Framework

Automation framework for Mint mobile trading application.

## Tech Stack
- Java
- Appium
- Selenium
- TestNG
- Maven

## Test Coverage
- Onboarding
- Login
- Buy Crypto
- Sell Crypto
- End-to-End Trading Flow

## Framework Design
- Page Object Model
- TestNG Runner
- Maven Build

## CI/CD
GitHub Actions pipeline runs automation tests automatically on push.
